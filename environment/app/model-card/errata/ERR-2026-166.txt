ERR-2026-166 — Degree damping on ranked scores
Status: shipping / extends scoring used for queries, holdout ranking, and folds

Let n_u be the number of distinct observed items for user u in the catalog
being scored (global catalog or remassed fold train catalog). Let n_i be
the number of distinct observed users for item i in that same catalog.

For any in-catalog pair, the RAW packed dot product is
  s_raw = dot(x_u, y_i)

The DAMPED score used for:
  - scores.json query outputs
  - holdout ranking metrics
  - fold ranking / map_at_k
is
  s = s_raw * sqrt( (n_u + n_i) / (n_u + n_i + gamma) )
with gamma = 5.0

Cold-start pairs (missing user or item) remain 0.0 (no damping).

diagnostics.json mean_abs_score MUST use abs(s_raw) over all catalog
user×item pairs (no degree damping). model.json stores undamped packed
factors as before.
