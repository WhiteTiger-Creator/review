ERR-2026-097 — Lambda schedule split
Status: shipping / supersedes constant lambda_t

Let M = 4.
For ALS iteration index t in 1..T (1-based):
  if t <= M: lambda_t = lambda
  else:      lambda_t = 2 * lambda

Use that lambda_t inside the ridge term for both the item block and the
user block of iteration t (still multiplied by n_i / n_u per ERR-2026-041).
