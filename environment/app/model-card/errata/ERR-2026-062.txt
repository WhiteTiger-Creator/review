ERR-2026-062 — Catalog min-mass filter
Status: shipping / supersedes model card catalog construction

Before dense indexing, drop any user_id whose total count across all items
in interactions.csv is strictly less than 2. Drop any item_id whose total
count across all users is strictly less than 2.

After dropping, also drop any interaction rows that reference a removed
user_id or item_id. Recompute totals are not required (single pass: first
compute totals on the raw file, drop low-mass IDs, then keep rows whose
both endpoints survived).

Dense indices and unit_hash initialization use only the surviving catalog,
sorted ascending as in the base card.
