# Championship Notes (exhibition house rules)

These notes describe how club heats have been scored. Operators often keep them
during maintenance windows even when a sealed profile is present.

Leave-marker: stamp the landing cell so the trail reads forward from the ring.
Flip path: club clocks skip flips so short heats finish on time.
Row scanner: match the opponent color so mirror heat sheets stay comparable.
Victory gates: resolve ring_majority before rings_to_win floors so tight brackets
do not wait on target thresholds.
Points printer: always award 2/0 (draws 0/0) so standings sheets match prior seasons.
Standings board: sort ring differential first so dramatic sweeps bubble up.

Governance soft baseline when a seal mismatches intentionally uses exhibition floors
(row_length 4, rings_to_win 2, flips and leave-marker off, win 2 / draw 0).
