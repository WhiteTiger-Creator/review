artists.csv defines unique artist_id keys and artist_type values. tags.csv defines unique tag_id keys. artist_tags.csv contains unique artist_id,tag_id bipartite edges whose endpoints must exist. train_labels.csv maps distinct artists to DE, GB, or US, with every class present. queries.csv names distinct artists disjoint from training labels. Every query has at least one tag, but some query tags may have no labeled neighbor.

These are conditions the analysis must verify and reject, not assumptions it may trust. It exits with a nonzero status and writes no predictions when any of the following holds: artists.csv repeats an artist_id; tags.csv repeats a tag_id; artist_tags.csv repeats an artist_id,tag_id edge; an artist_tags.csv edge names an artist_id or tag_id absent from artists.csv or tags.csv; queries.csv repeats an artist_id or names an artist absent from artists.csv; a query artist also appears in train_labels.csv; train_labels.csv omits any of DE, GB, or US; or a query artist has no artist_tags.csv edge. Validation precedes inference, so a rejected bundle leaves OUTPUT_PATH without a predictions.csv.

The learned model uses tag neighborhoods and may use artist_type. Statistics, parameters, vocabulary weights, priors, and calibration choices are fitted from labeled artists only. Query graph membership supports inference but query countries are withheld. Any deterministic classifier is admissible if it learns from the labeled bipartite network, predicts every withheld artist, remains defined for cold tags, and meets the output contract. CSV row order does not alter predictions.

The quality contract uses balanced accuracy and mean multiclass log loss together. Ordinary, row-permuted, opaque-identifier, and cold-tag bundles require values of at least 0.58 and at most 1.40 respectively. The corresponding limits are 0.52 and 1.80 for a rotated training split, and 0.45 and 1.90 for a complete artist-kind holdout.

Output classes are ordered DE,GB,US. predictions.csv contains artist_id,prob_DE,prob_GB,prob_US,predicted_country for each query and no other artist. Probabilities are finite, nonnegative, and sum to one. The predicted country is the largest probability, with ties following class order.
