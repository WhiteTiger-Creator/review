Input rows live in /app/data/train.csv. Config files live in /app/config. The target column is satellites. Numeric features are fit-median imputed before centering and sample-SD scaling. Categorical features replace fit-side blank, NA, NaN, nan, null, ?, and MISSING values with __missing__ before sorting fit levels; append __missing__ only if it was absent from fit levels, append __other__ last, and map unseen non-fit levels to __other__.
