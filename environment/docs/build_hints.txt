Workspace root - /app/environment

Build
  cargo build --release --bin ferric_drv

Public wrapper
  /app/environment/run_ferric_drv

Wrapper cwd must be the workspace root. Emits under /app/emit/.
CARGO_TARGET_DIR defaults to /tmp/ferric-target.

Optional overrides (environment variables)
  FERRIC_NEST - path to nestmap JSON (default data/nests/nest_map.json)
  FERRIC_GRID - path to grid JSON (default data/grids/grid_pub.json)
  FERRIC_EMIT - emit directory (default /app/emit)
  FERRIC_ROOT - workspace root (default /app/environment)

Held-out nestmap cases - /app/environment/data/nests/nest_hold.json
Held-out grids - /app/environment/data/grids/held_out.json

Smoke snapshots (non-authoritative; not for production emit)
  /app/environment/lib/snap_x.rs
  /app/environment/lib/snap_y.rs

Workspace sources include
  /app/environment/slag/src/slag_bind.rs
  /app/environment/kiln/src/kiln_forge.rs
  /app/environment/flint/src/flint_sift.rs
