Crystal Cellar Push
===================

The Ruby runner reads a batch of cellar boards from standard input and prints one result per board. A route can require pushing crystal blocks onto floor seals, sliding them along frozen channels, and planning around cracked tiles that collapse after a block crosses them.

Input starts with the number of boards. Each board has a header with its name, row count, and column count, followed by exactly that many grid rows. Run `ruby bin/crystal-cellar-push` from this directory. The short cases in `examples.json` demonstrate the input and output format.
