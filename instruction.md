The fleet defense simulation at `/app/` models a network topology where symlink chains represent supply routes between sectors. The simulation engine scores sector health based on route integrity, propagates damage through connected routes, computes zone aggregate scores, and determines zone and fleet-wide verdicts. The engine runs via `cd /app && make clean && make && ./bin/symlink-health --manifest /app/data/manifest.json --config /app/config --output /app/output/health_report.json` and produces a JSON game state report, but the current scoring and rule enforcement does not conform to the simulation ruleset documented in `/app/docs/topology-contract.md`.

Current rule violations: cycle ring depth is miscalculated for routes that enter an established cycle without being ring members, damage propagation ignores zone boundaries causing cross-zone contamination, the scoring subsystem applies priority weighting before penalty deduction rather than after, zone aggregate normalization does not account for per-route priority ceilings in the denominator, fleet-wide scoring uses uniform averaging instead of capacity-weighted computation, and the verdict determination does not enforce the three-tier escalation with critical-count override.

The simulation must enforce all rules in the topology contract. The output JSON requires top-level keys `summary`, `overall_status`, `entries`, `segments`, and `metadata`. Route entries carry `path`, `status`, `chain_depth`, `final_target`, `segment_group`, `health_score` (2 decimal places), `taints` (string array), and `detail`. Zone aggregates carry `id`, `name`, `total`, `healthy`, `unhealthy`, `aggregate_score` (4 decimal places), and `verdict`. Fleet score rounds to 4 decimal places. Metadata includes `max_chain_depth`, `permission_mask`, `score_threshold`, `scoring_mode`, `config_source`, and `timestamp` sourced from the manifest's `scan_timestamp` field. The simulation must exit 0 and produce deterministic output across runs. Note that code comments and docstrings may themselves contain errors.
