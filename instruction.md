Offline restart-storm budget tooling under `/app/environment` is drifting across ops cycles. Cold and hot digests diverge on graded bundles. Later profile rows inherit tallies from earlier ones across scrub and preserve churn. A durable epoch bus under `/app/environment/pack/seed` must stay coherent with tip selection, policy bind, staging checkpoints, and hit-cache identity across bare scrub and preserve-anchor recovery. n3_v1 stays unavailable with storm generation poisoned, or with the durable epoch record under `/app/environment/pack/seed` disagreeing with the live tip.

Repair the Go sources under `/app/environment`, rebuild with `bash /app/environment/scripts/build_all.sh`, and run `/app/environment/bin/wave_sched --grid-full --out /app/output/storm_trace.json`. A good run exits 0 and also writes `/app/output/replay_audit.json`.

Graded storm_trace format is n3_v1 with a grid of four families: wave_alpha, wave_beta, wave_gamma, and wave_delta. Each row carries family, lane_order, span_band, span_digest, cold_digest, and hot_digest. Digests are lowercase hex length 64. span_digest is the sealed hex digest over unit slice bytes, incident wave bytes, and for each active lane in lane_order that lane's mask as little-endian uint16 plus its arm-id slot byte, plus the eight-byte staging prefix that fed ranking. cold_digest uses that same seal with the first eight bytes of `/app/environment/pack/seed/token_seed.bin` as the staging prefix. hot_digest uses that same seal with the staging bytes that actually fed lane ranking (gen-bound checkpoint `/app/environment/pack/checkpoints/stg_g{N}.bin` when present for the epoch-bus bound generation N, otherwise `/app/environment/pack/seed/.anchor_staging`). On a converged row the three digest columns match. span_band sums hit tallies across every active include arm past suppression, not only lane_order members.

Pack field paths that must survive preserve-anchor unchanged: `/app/environment/pack/w8/sg.slice`, `/app/environment/pack/w8/sd.slice`, `/app/environment/pack/incidents/sg.inc`, and `/app/environment/pack/incidents/sd.inc`.

Ledger tip is the largest gen among records in `/app/environment/pack/ledger/waves.ndjson` whose tomb field is false. Overlay selection loads `/app/environment/pack/policy/ov_g{N}.json` for tip generation N. The audit field policy_path records that file as a path relative to `/app/environment`: the three path segments pack, policy, and ov_g{N}.json joined by slashes. Overlay JSON carries gen, shadow_radius, and policy_id.

Shadow suppression uses the active overlay shadow_radius as distance threshold R. An include arm is suppressed for any exclude arm with non-zero shadow_link that shares a mask bit and where abs(id - link) meets or exceeds R. Exclude arms ordered by ascending Seq contribute suppression; include arms form the active set next. Graph readers observe the live overlay radius from the selected overlay or from a probe-installed temporary overlay.

Hit-cache identity covers family, selected overlay generation, shadow epoch, cell layout dimensions, a signature over incident field bytes, and the durable epoch-bus identity counter. On a successful tally the burst grid cache epoch matches its shadow epoch. Across scrub and preserve cycles, tallies from earlier bus generations must not leak into later families.

lane_order ranks by descending hit score, then by descending staged-anchor byte at arm_id modulo 8, then by ascending arm id, capped by the profile budget. Gen-bound staging for production ranking follows the epoch-bus bound generation past tip and policy resolution.

Emitting n3_v1 is refused if `/app/environment/pack/seed/.storm_gen` is non-zero or `/app/environment/pack/seed/.epoch_bus.json` shows bound generation out of sync with the ledger tip or storm_ok false. Cold and hot prefixes must agree for those digests to converge. A mismatched staging prefix (including the eight-byte sample HOTSTG01 or a one-byte flip versus the cold seed) blocks n3_v1 on the hot path with no matching gen-bound checkpoint binding the tip.

The epoch bus JSON schema is object fields token (uint), bound_gen (int), storm_ok (bool), and rev (uint). Observable across scrub, preserve, and a successful grid-full run: bound_gen equals the ledger tip, storm_ok is true with storm_gen at 0, and the bus identity counter is higher than its pre-scrub value. Digests diverge or emit stays blocked wherever those fields disagree with the live tip.

Ops recovery is `bash /app/environment/phase/rld_x2.sh`. A bare call with no flags increments the roll counter, drops staging, poisons storm_gen, mutates the wave ledger, and invokes `/app/environment/bin/epochctl invalidate`. Two bare resets with no preserve leave the grid unable to emit n3_v1. Running that recovery script in preserve-anchor mode restores seed staging from token_seed.bin, clears the roll counter, clears storm_gen poison to 0, restores ledger coherency from the clean checkpoint, and invokes `/app/environment/bin/epochctl restore`, without mutating the pack field blobs listed above.

replay_audit must report tip_gen, policy_gen, policy_id, policy_path, and ledger_fingerprint (hex fingerprint of waves.ndjson bytes) consistent with the ledger tip and selected overlay. policy_path must be that same relative form for the tip generation (segments pack, policy, ov_g{tip}.json joined by slashes), not an absolute filesystem path.

Profile decode options permute and swap_masks reshape scoring arms, but digest prefixes still hash the on-disk unit slice and incident wave bytes. Interim rows in `/app/environment/pack/inter_m5.json` are smoke-only and must not match graded digests.

Hand-written JSON and static copies are not enough. Source under `/app/environment` has to be fixed. Rebuilt libraries must pass the offline package probes under `/tests/lib_probe`. Those probes install a temporary active overlay (generation, shadow radius, policy id, and path) through the policy package probe entry; shadow and ranking checks observe that radius without tip selection. That probe entry must remain available past source repairs. The driver must emit the contracts above. Rebuild also produces `/app/environment/bin/epochctl` used by the recovery script.
