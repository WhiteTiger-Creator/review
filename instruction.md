Six copyists produced manuscript pages represented by ten layout features. Train a multiclass model that predicts the copyist of held-out pages. Most training pages have no canonical label: seven overlapping workers supplied noisy labels, omitted pages they could not judge, and each used a private six-symbol vocabulary with an unknown one-to-one correspondence to the canonical classes. Sparse anchors connect some worker reports to known copyists. The statistical challenge is to learn the private correspondences and worker trust while using features to generalize beyond anchored pages.

The input directory contains relational CSV tables for page features and train/query membership, sparse anchors, worker-local annotations, worker vocabularies, and the canonical class list. Missing worker-page pairs are abstentions and contribute no class evidence. Every worker vocabulary is a permutation of the complete canonical class set, but its symbol names and mapping can change between evaluation bundles. The fitted model must therefore remain invariant to consistent private-symbol renaming and input row order. Details of table columns, uniqueness rules, and the required prediction schema are in /app/docs/contract.md.

Create /app/model.R as a self-contained R analysis. It reads WL_DATA_DIR and writes WL_OUTPUT_PATH. Report exactly one row per query page, a canonical predicted class, and normalized probabilities for all six classes. Evaluation refits the model on unseen bundles, then measures balanced accuracy and multiclass log loss against withheld canonical copyists. R and nnet are installed, execution is offline, and the analysis is launched with Rscript /app/model.R.
