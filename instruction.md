Complete tournament adjudication for Tidefront, a terminal strategy game under `/app`. The supported command is `/app/bin/tidefront adjudicate`. It must replay a complete match across the supplied graph board, simultaneous fleet orders, and turn-varying water depths, then write the canonical game result requested by `--output`.

The complete match schema, movement legality, collision priority, chain and cycle behavior, territory capture, cumulative scoring, winner tie breaks, output ordering, digest format, and fail closed requirements are defined in `/app/docs/game-contract.md`. The board's water-depth mechanic and its data formats are documented in `/app/docs/tide-mechanics.md` and the linked schema documents.

Verification may create additional valid boards, players, fleets, orders, tide states, leap-boundary turns, worker counts, and output paths. The adjudicator must implement the general game rules rather than depend on the bundled example. It must remain offline and deterministic. Python is not permitted in `/app` or in the solution workflow.
