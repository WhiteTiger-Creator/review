The fleet readiness evaluation pipeline at `/app/` computes multi-class classification metrics for vehicle readiness predictions. The pipeline loads model prediction scores from `/app/data/predictions/`, compares against ground truth labels in `/app/data/ground_truth/labels.json`, applies Platt-scaling confidence calibration and exponential temporal decay weighting, then produces per-class precision/recall/F1 and aggregate fleet readiness scores. Run with `python3 /app/run_evaluation.py`. The evaluation must satisfy all requirements in `/app/docs/eval-protocol.md` including calibration via temperature division, ln(2)-based temporal decay, cold-start exclusion for assets below the minimum prediction threshold, multiplicative priority weighting in the fleet aggregate, and penalty-after-normalization ordering. Results write to `/app/output/eval_report.json` with 4-decimal-place metric precision. Note that code comments and docstrings may themselves contain errors.
