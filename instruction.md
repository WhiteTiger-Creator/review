Please create `/app/analysis.R` for an offline regression model that predicts horseshoe crab satellite counts from shell color, spine condition, body width, and weight. Read `/app/data/train.csv`, config files from `CONFIG_DIR` when set otherwise `/app/config`, and optionally `/app/starter`; honor `DATA_PATH`, then `DATA_DIR/train.csv`, otherwise the default data file. Write fresh artifacts to `OUT_DIR`, then `OUTPUT_DIR`, otherwise `/app/outputs`; `OUT_DIR` wins when both are set.

Rows marked fit are the only rows for learning preprocessing choices and candidate settings, validation rows select and report the active setting, and test rows have blank public targets. Required outputs are `predictions.csv`, `validation_predictions.csv`, `metrics.json`, `selection_report.csv`, `feature_summary.csv`, `group_error_report.csv`, `neighbor_evidence.csv`, `interval_report.csv`, `residual_bins.csv`, and `feature_pair_stress_report.csv`.

Use the configured closed-form ridge model on the encoded design, with `k_grid` values as lambda candidates and `log1p` target fitting when active training targets are nonnegative. Numeric preprocessing is fit-median imputation, then mean/sample-SD scaling over the imputed values. Categorical preprocessing uses full one-hot encoding: replace missing tokens with `__missing__`, keep one column for every learned level, never drop a reference level, and map unseen non-fit levels to `__other__`. `validation_predictions.csv` uses the fit-only selected model. Its interval report uses selected-k nearest fit-row target quantiles at 0.08 and 0.92 in the encoded validation space, while final test predictions, neighbor evidence, and pair stress refit on fit plus validation rows in original CSV order. `/app/config/artifact_contract.csv` owns exact schemas, row scope/order, group-stability selection, interval details, feature-pair stress size/details, and final combined-reference level rules.
