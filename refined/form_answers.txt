SECTION 3 - summary of changes

Both points from the feedback are fixed. The nonce store in webhook_signature.ts now drops a nonce once the timestamp it was signed under is more than 300 seconds old, so it doesn't grow forever and it won't refuse a nonce that comes back after the window. Fixing that showed a problem in my own inputs: SIG-006 was logged 589 seconds after SIG-002 with a fresh timestamp, so a properly windowed store would have let it through, which contradicted the incident thread and the rubric. I moved SIG-006 to 09:04:11 with a 126-second skew so it's a real resend of SIG-002 inside the window that only the nonce check catches, moved SIG-003 to SIG-005 earlier so the log stays in order, and rewrote the line in incident_thread.txt that said twelve minutes. I also put the nonce into the signed string in the input webhook_signature.ts, because otherwise anyone replaying a request could just change the nonce header.

callback_fetch.ts still refuses literal private, link-local and loopback hosts first. An allowlisted host now gets resolved with node:dns and refused if any address comes back private, link-local or loopback (IPv6 and IPv4-mapped included), and the request connects to the address that was checked so the DNS answer can't change in between. It compares the full registered origin, so http or another port on the approved host is refused, and it takes the provider from the verified key instead of the payload. The regression suite went from 14 tests to 27. I ran it under Vitest and all 27 pass, and the new expiry and DNS tests fail when the old behaviour is put back.

I rewrote the rubric so every criterion checks one thing (46 positive, 11 negative) with separate criteria for DNS resolution, nonce expiry and their tests. I also took callback confirmation out of the Partner Integrations ownership criterion, since the standard never assigns it; the golden now sends callback failures to each provider's owner from the delivery inventory. The prompt is unchanged, and nothing from the feedback was left open.
